# DevOps-Lad04 — FixFlow

## คำอธิบายโครงการ

FixFlow เป็นหน้าเว็บศูนย์ช่วยเหลือด้าน IT สำหรับพนักงาน ใช้แจ้งปัญหาคอมพิวเตอร์ ระบบเครือข่าย โปรแกรม อีเมล และอุปกรณ์สำนักงานผ่านแบบฟอร์มเดียว พร้อมแสดงประเภทบริการและขั้นตอนการรับเรื่องในรูปแบบที่ใช้งานง่าย รองรับการแสดงผลทั้งบนคอมพิวเตอร์และอุปกรณ์เคลื่อนที่

โครงการนี้เป็นตัวอย่างหน้าเว็บส่วนหน้า (frontend) ที่พัฒนาด้วย HTML, CSS และ JavaScript โดยยังไม่ได้เชื่อมต่อระบบหลังบ้าน เมื่อส่งแบบฟอร์มจะแสดงข้อความยืนยันตัวอย่างเท่านั้น และไม่มีการบันทึกหรือส่งข้อมูลไปยังทีม IT จริง

## คุณสมบัติ

- แบบฟอร์มแจ้งปัญหา พร้อมตรวจสอบช่องข้อมูลที่จำเป็น
- แสดงหมวดหมู่บริการและขั้นตอนการรับเรื่อง
- เมนูนำทางไปยังส่วนต่าง ๆ ของหน้า
- รูปแบบ Responsive สำหรับหน้าจอขนาดต่าง ๆ
- แสดงปีปัจจุบันในส่วนท้ายของหน้าเว็บ

## วิธีเปิดใช้งาน

ไม่ต้องติดตั้ง dependencies หรือ build โปรเจกต์:

1. ดาวน์โหลดหรือ clone repository
2. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์

## ไฟล์หลัก

- `index.html` — โครงสร้างหน้าเว็บ สไตล์ และ JavaScript สำหรับการทำงานของแบบฟอร์ม
